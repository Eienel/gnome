The problem

Agents hold crypto. APIs still want credit cards.

An autonomous agent can't sign up for a card, and nothing stops it from running up an unbounded bill. Gnome fixes both: pay-as-you-go access with a hard cap enforced by the payment itself. When the balance runs out, the calls stop. There is no overdraft.

How a paid call works

402 → sign → settle → serve

01

402 Payment Required

The agent calls a paid endpoint and gets back the price and payment terms.

02

Sign authorization

It signs an EIP-3009 transferWithAuthorization with its EVM key.

03

Settle on-chain

The facilitator submits the transfer to Robinhood Chain and pays the gas.

04

Serve the result

Only after settlement does the upstream API run and return its result.

🔒

Hard spend cap

The balance is the ceiling. No subscriptions, no surprise invoices, no overdraft — enforced by the transfer itself.

For developers

Point an agent at the rail. It pays itself.

Wrap fetch with a payer built from your agent's private key. Every HTTP 402 is signed and settled transparently.

agent.ts
// pay-per-call, capped by the agent's on-chain balance
import { createPayer, wrapFetchWithPayment } from "gnome/client";

const payer = createPayer(process.env.AGENT_PRIVATE_KEY);
const pay   = wrapFetchWithPayment(fetch, payer);

// the 402 is signed & settled on Robinhood Chain automatically
const res = await pay("https://gnome.app/v1/speak", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: "Hello, paid on-chain." }),
});
const audio = Buffer.from(await res.arrayBuffer()); // your MP3
