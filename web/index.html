APIs still want cards.

An autonomous agent cannot sign up for a credit card, and nothing stops it running up an unbounded bill. Gnome gives it pay-as-you-go access with a hard cap enforced by the payment itself. When the balance runs out, the calls stop. No overdraft.

How a paid call works

402, sign, settle, serve.

01

402 required

The agent calls a paid endpoint and gets back the price and terms.

02

Sign

It signs an EIP-3009 authorization with its EVM key.

03

Settle

The facilitator submits the transfer on chain and pays the gas.

04

Serve

Only after settlement does the upstream API run and return.

Provision a key See it pay
agent.ts
// capped by the agent's on-chain balance
import { createPayer, wrapFetchWithPayment } from "gnome/client";

const payer = createPayer(process.env.KEY);
const pay   = wrapFetchWithPayment(fetch, payer);

// the 402 is signed and settled for you
const res = await pay("/v1/speak", {
  method: "POST",
  body: JSON.stringify({ text: "paid on chain" }),
});
